# 翠渓 SUIKEI - clear stream angler (Godot 4)

An original mountain-stream fishing game built in Godot 4.3 (Compatibility renderer).
Play in the browser: https://aeiouvcode.github.io/suikei-godot/

Tap the water to cast. When the float dives, tap to set the hook. Hold to reel and let go
when the line strains. Land it, log it in the journal, release it, then move upstream.

- Turquoise water with depth absorption, refraction and chromatic caustics
- 8 Japanese stream species (plus one rare pool master), 4 pools
- Washi paper and sumi ink UI, gyotaku catch cards, size records

Source project: `source/` (open `source/project.godot` in Godot 4.3).
Fonts: Shippori Mincho and Noto Serif JP (SIL Open Font License), subset.
